# Ignacio Leiva · Proyectos en 3D / 3D engineering projects

**ES** · Portafolio de Ignacio Leiva, estudiante avanzado de Ingeniería Mecánica (UTN FRSF). Muestra cuatro proyectos animados en 3D, que se pueden girar con el mouse o con el dedo:

1. Sistema de descarga de big bag (trabajo integrador, UTN FRSF).
2. Elevador paternóster de cajones (trabajo integrador, UTN FRSF).
3. Pulidora automática de tanques (Proyecto Final de Carrera, en curso).
4. Circuito de refrigeración del aceite y del generador de una turbina de gas (modelo propio, hecho como ejercicio durante la Práctica Profesional Supervisada).

Los modelos son ilustrativos y simplificados, y no llevan datos de clientes ni de plantas. Es una sola página (`index.html`) hecha con [three.js](https://threejs.org/). Para verla en inglés, agregá `?lang=en` a la dirección.
